# TRUE Upskill Brand Guideline

Lives at https://brand.trueupskill.com

TRUE Upskill is a separate brand from TRUE Original. Its own domain, its own mark,
its own typeface. The TRUE style guide at https://style.true.gate1.dev links here
and does not govern this brand.

## The site sets the rules

trueupskill.com is the source of truth, decided by Patrik 2026-07-25. If this
guideline and the live site disagree, the SITE is correct and this document gets
updated, never the other way round.

The real values live in the TRUE-Catalog repo, `src/styles/global.css`. Read them
there rather than trusting this page from memory.

## Deploy

Static, no build step, served with `bunx serve` on the repo root.
Merge to master, then `gate project deploy true-upskill-brand --rebuild`.
There is no push to live on this project.
